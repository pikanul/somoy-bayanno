# Dainik Somoy Bayanno

`দৈনিক সময় বায়ান্ন` / The Daily Somoy Bayanno is a production-grade Bangla news portal to be built with Laravel, Filament, Blade, Livewire, Alpine.js, and MySQL/MariaDB.

This project will be developed phase-by-phase. Each phase should stay focused, avoid unrelated changes, and be verified before the next phase begins.

## Foundation Configuration

- Application name: The Daily Somoy Bayanno
- Timezone: Asia/Dhaka
- Primary language: Bangla (`bn`)
- Fallback language: English (`en`)
- Database: MySQL/MariaDB using `somoy_bayanno` with `utf8mb4` character support for full Unicode and Bangla text
- Development environment: Local Laravel development with `APP_ENV=local`, debug enabled only for local work, file-based sessions/cache, and synchronous queue processing
